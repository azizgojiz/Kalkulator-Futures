# Kalkulator Futures (Leverage + PnL)

Gabungan dari 2 project:
- Kalkulator Leverage (dulu: kalkulator-futures)
- Kalkulator PnL (dulu: kalkulator-futures-PnL)

Sekarang jadi satu aplikasi Streamlit dengan 2 tab.

## Cara jalanin di komputer sendiri
1. Install Streamlit: `pip install -r requirements.txt`
2. Jalankan: `streamlit run app.py`

## Cara deploy ke Streamlit Cloud
1. Upload semua file di folder ini ke satu repo GitHub.
2. Buka https://share.streamlit.io, hubungkan ke repo tersebut.
3. Set "Main file path" ke `app.py`.
4. Deploy.
